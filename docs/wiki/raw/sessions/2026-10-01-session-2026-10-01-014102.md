### The wiki-on/wiki-off control arm is a CLI switch rather than a code change: `pi -ne` disables the discovered extension and skill, and `--tools`/`--exclude-tools` produce an otherwise identical tool allowlist with the wiki_* tools removed, so an A/B run is reproducible without a special build of the package.

### Efficacy measurement uses rediscovery rate (the share of a retrieved page's `files:` links that the agent still reads afterwards) as the mechanism metric, on the reasoning that cost and tool counts cannot separate a wiki that answered a question from a wiki that was visited before the answer was found in the code — and because the join needs no model call, it can be computed for both arms from the same analyzer.
Kind: decision
Evidence:
