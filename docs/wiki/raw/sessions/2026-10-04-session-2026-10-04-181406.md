### Auto-retrieval is on by default: every prompt searches the session wiki and, when Jev's sufficiency verdict passes `search.jev.minSufficiency`, an `<auto-retrieval>` brief is injected with the prompt before the first provider request. It is session-wiki-only — other registered wikis and the global vault stay a manual `wiki_ask`, documented in the llm-wiki skill — and it fails closed: no verdict, low sufficiency, or `budgetMs` expiry injects nothing.

### The pre-turn injection mechanism is pi's `before_agent_start` hook returning a `custom_message`: pi appends handler messages to the same batch as the user prompt, before the first provider request, so the brief is both rendered in the transcript and present in LLM context. `display` controls TUI rendering only — a custom message is in context either way — so display-without-context requires `appendEntry` plus `registerEntryRenderer` instead. A trailing message also preserves the cached prompt prefix, unlike a system-prompt change.
