## About

Jev is TypeSafe AI's first System One model, released September 15, 2026 in early access. Built for automation workflows, Jev maps unstructured state to typed probabilistic decisions with parallel structured outputs, trained with Reinforcement Learning for Calibrated Decisions (RLCD). TypeSafe positions Jev as a frontier-intelligence function call—unstructured input in, calibrated decisions out—rather than a general chat or copilot model.
